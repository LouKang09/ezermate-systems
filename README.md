# EzerMate Systems

POS and business technology website for ezermatesystems.com.

Run with Node.js 22+: `npm start`. No dependencies or build step. The server listens on PORT (default 3000). JavaScript checks: `npm run check`. Railway uses the Dockerfile and /health endpoint.

The POS playground uses sample products and processes no real orders or payments. The contact form opens an email draft to inquiries@ezermatesystems.com; no form data is stored by this website. Mailbox provisioning is separate.

Responsive desktop, tablet and mobile layouts; keyboard navigation; reduced-motion support.
